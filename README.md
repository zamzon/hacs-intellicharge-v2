# IntelliCharge V2 for Home Assistant

Custom Home Assistant integration for IntelliCharge using the current v2 API.

## Features

✅ Login with IntelliCharge account

✅ Read custom charging rules

✅ View charging rules in Home Assistant

✅ Configure minimum battery SOC after sell

✅ Native Home Assistant entities

✅ Home Assistant Config Flow

## Requirements

- Home Assistant 2025.1+
- IntelliCharge account
- Plant ID

## Installation

### HACS

1. Open HACS
2. Go to Integrations
3. Click Custom Repositories
4. Add this repository
5. Select Integration
6. Install
7. Restart Home Assistant
